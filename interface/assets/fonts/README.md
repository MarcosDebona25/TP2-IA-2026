# Fuentes de la interfaz

Se sirven embebidas en el CSS (ver `interface/theme.py`) para que la UI se vea igual sin
conexión a internet (p. ej. en la presentación del congreso).

| Archivo | Familia | Licencia |
|---|---|---|
| `plus-jakarta-sans-latin-wght-*.woff2` | Plus Jakarta Sans (variable, 200–800) | SIL OFL 1.1 (`OFL.txt`) |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono (variable, 100–800) | SIL OFL 1.1 |

Origen: paquetes `@fontsource-variable/*` 5.1.1 (subset latin: incluye acentos y ñ).
